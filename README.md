# モナと學ぶ日本語 · N4 Quest

和摩爾加納一起探索日文 N4 單字與文法，並在日本喫茶店情境中練習點餐、付款與用餐禮儀。首頁提供遊戲預覽，可依喜歡的玩法開始練習。

## GitHub Pages

- [N4 遊戲大廳與遊戲預覽](https://heidilee2324.github.io/n4-japanese-quest/)
- [N4 主線冒險遊戲](https://heidilee2324.github.io/n4-japanese-quest/n4-quest.html)
- [N4 單字翻牌配對](https://heidilee2324.github.io/n4-japanese-quest/n4-memory.html)
- [喫茶店日語冒險](https://heidilee2324.github.io/n4-japanese-quest/mona-cafe/)

## 遊戲入口

- index.html：N4 遊戲大廳，預覽目前的遊戲。
- n4-quest.html：七個主題關卡、21 題的 N4 單字與文法冒險遊戲。
- n4-memory.html：日文單字與中文意思翻牌配對，答對會顯示假名讀音與例句。
- mona-cafe/index.html：喫茶店角色扮演冒險，共 8 個會話情境；練習常用餐廳單字、〜をください點餐句型、付款表達和餐後禮貌。

## 主線冒險操作方式

- 電腦：使用 WASD 或方向鍵移動摩爾加納。
- 觸控裝置：按住畫面下方的方向鍵移動。
- 靠近並碰觸其中一個日文選項即可作答。

## 喫茶店冒險操作方式

- 使用 WASD 或方向鍵移動角色，走到櫃台附近按空白鍵或「互動」按鈕開始點餐。
- 依對話線索選擇日語回應；店員的反應與提示會協助理解句型並修正答案。

既有 N4 主線遊戲使用 Phaser 3.90.0，字型與 Phaser 由 CDN 載入；喫茶店冒險是獨立的 HTML Canvas 遊戲。遊戲需要網路連線以載入 GitHub Pages 與既有 CDN 資源。
