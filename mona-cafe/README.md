# モナの日常：喫茶店日語冒險

日本の喫茶店を舞台に、店員との会話を通じて注文、店内飲食・持ち帰り、飲み物の選択、支払い、食事の礼儀を練習するロールプレイゲームです。

## 學習重點

- 日語 N4 實用詞彙與餐廳常用表達
- `〜をください` 等點餐句型與付款表達
- 閱讀對話線索，選擇合適的回應並查看店員反應
- 透過提示理解錯誤原因，再修正答案

## 操作方式

- 使用 `WASD` 或方向鍵移動角色。
- 走到櫃台附近後按空白鍵或「互動」按鈕開始點餐。
- 依照對話選擇答案；完成點餐後繼續完成用餐任務。
